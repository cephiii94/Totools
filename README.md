# Totools

Kumpulan tools ringan berbasis HTML, CSS, dan JavaScript vanilla.

## Struktur

```text
Totools/
├── index.html
├── Index-1.html
├── assets/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── script.js
└── README.md
```

## Tools saat ini

- Konversi mata uang
- Penerjemah teks
- Barcode generator
- QR Code generator

## Cara pakai

Buka `index.html` langsung di browser, atau upload folder ini ke hosting statis seperti GitHub Pages, Netlify, atau Vercel static hosting.

## Catatan dependency

Beberapa tool memakai CDN:

- JsBarcode untuk barcode
- QRCode.js untuk QR Code
- JSZip untuk download batch QR sebagai ZIP
